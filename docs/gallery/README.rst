Example gallery
===============

Short programs, grouped by task. The documentation build runs every one of them
and fails if one raises or an assertion in it stops holding, so each plot and
audio player below is the output of the code on its page. All signals are
generated in the code, so a page can be copied and run with no audio files.

The longer explanations are in the :doc:`tutorials </tutorials/index>`. Each
section below lists the notebooks that cover its topic. For the same tasks in
Rust, see the gallery chapter of the crate's book.
